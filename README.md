# Federated Learning: A Survey of Privacy-Preserving Distributed ML

A literature survey on federated learning (FL), written in IEEE conference format.

## Overview
This survey covers:
- Problem formulation and Federated Averaging (FedAvg)
- Taxonomy: horizontal, vertical, transfer FL; cross-device vs cross-silo
- Algorithms for non-IID data: FedProx, SCAFFOLD, FedOpt
- Communication efficiency, systems heterogeneity
- Privacy (secure aggregation, differential privacy) and security (poisoning, backdoors)
- Fairness and personalization (q-FFL, Per-FedAvg)
- Applications and open research problems
